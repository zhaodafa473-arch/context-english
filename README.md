# 语境英语 · Context English

一个从文章里学英语的小工具。一篇文章走四步：**读 → 听 → 说 → 写**，然后用间隔重复把词留住。

- 纯静态网页，无构建、无依赖、无后端，所有数据存在浏览器本地
- 手机可用：浏览器打开 → 添加到主屏幕 → 全屏运行、可离线
- 面向 **四级 / 雅思托福 / 日常交流**：三篇文章分别是外刊评论、生活对话、学术说明

## 线上地址

**<https://zhaodafa473-arch.github.io/context-english/>**

手机打开这个网址 → 浏览器菜单「添加到主屏幕」。装好之后：

- 出门、不连家里的 WiFi 也能打开
- 内容已缓存，**没网也能读**
- 是 https，所以「说」的麦克风能正常用

> 数据只存在**打开它的那台设备**里。电脑和手机各自独立。
> 换设备、或者担心浏览器清数据，用「备份与恢复」搬（见下）。

## 备份与恢复

进度只存在**打开它的那台设备**的浏览器里，不上传、不联网。所以：

**首页底部 →「备份与恢复」**

| 按钮 | 做什么 | 用在哪 |
|---|---|---|
| 复制备份码 | 把全部进度压成一段 `CE1:...` 文本放进剪贴板 | 手机上最方便，贴进备忘录 / 微信收藏 / 发给自己 |
| 分享到… | 调系统分享面板（发微信、存笔记、邮件） | 手机 |
| 存成文件 | 下载一个 `.json` | 电脑，或者想存进网盘 |
| 恢复 | 粘贴备份码，或选文件 | 换手机、清了缓存之后 |

几个要点：

- **备份码是压缩过的**：300 个词约 3.5 KB 文本，不是几十 KB
- **恢复是合并，不是覆盖**：同一台设备上已有的词不会被冲掉；同一个词取更熟练的那份
- **内容一样，格式两种**：备份码和 `.json` 文件可以互相导入，粘错也能认
- 首页在超过 7 天没备份、且生词 ≥ 5 个时，会提示一次

## 怎么跑起来（本地开发用）

**电脑上**

双击 `start.cmd`。它会用 Python 起一个本地服务器并打开
<http://localhost:8787>。

> 为什么不能直接双击 `index.html`？因为「说」要用麦克风，浏览器只在
> `localhost` 或 `https` 下才允许。用 `file://` 打开时，录音会被浏览器拦住。

**手机上（家里局域网）**

同一 WiFi 下，用 `http://电脑IP:8787` 能读能听，但麦克风仍会被拦——
手机浏览器只对 `https` 放开麦克风。要完整用「说」，用上面的线上地址。

## 四个动作在练什么

| 步 | 做什么 | 为什么这样设计 |
|---|---|---|
| 读 | 点带虚线的词，出一张「语境卡」 | 学的是**词在这个句子里的意思**，不是词典第一条释义 |
| 听 | 盲听整篇，或逐句听写 | 听写会逐词标出你漏了哪个，比「听懂了」可靠 |
| 说 | 跟读三句并录音回放 | 只为让你自己听见差别，不评分、不纠口音 |
| 写 | 用当天的词写 3 句 | 用出来一次，胜过认十次 |

语境卡不是单词卡，它是五件事：

1. **它在文章里** —— 带上下文的原句
2. **拆开看** —— 词根词缀，或者构词逻辑
3. **怎么搭** —— 固定搭配，比孤立释义有用
4. **别搞混** —— 和最容易混的那个词辨析
5. **作者为什么用这个词** —— 语气、正式度、隐含态度

## 复习怎么安排

简化版 FSRS，6 级熟练度，间隔 **0.25 / 1 / 3 / 7 / 16 / 35 天**。

题型随熟练度变难，始终只考「产出」不考「认出」：

- 0–1 级：填原文句里的空
- 2–3 级：给搭配，填这个词
- 4–5 级：只给中文，自己写英文

答错 → 降一级，本轮末尾再出一次，明天再见面。答对 → 升一级。
到 35 天间隔还会继续出现，不会「消失」。

## 目录结构

```
english-app/
  index.html              入口
  manifest.webmanifest    PWA 清单
  sw.js                   离线缓存
  start.cmd               本地服务器（双击运行）
  assets/
    data.js               全部内容：文章 / 词条 / 语法点 / 跟读句 / 写作题
    app.js                应用逻辑：路由、阅读器、四技、复习、生词本

    icon*.png|svg         图标
  tools/
    shot.mjs              用 CDP 模拟手机视口截图（开发用）
    make_icons.py         重新生成图标（开发用）
```

**要加文章，只改 `assets/data.js`**，不用碰别的文件。一篇的结构：

```js
{
  id: 'books',                    // 唯一标识，也是网址里的 #/article/books
  kind: 'press',                  // press | dialogue | academic
  kindLabel: '外刊评论',
  title: 'Why We Keep Buying Books We Never Read',
  subtitle: '关于「买了不读」',
  level: 'B1+',
  intro: '中文导读，一句话',
  tip: '读的时候注意什么',
  paragraphs: [
    { text: '正文段落……' },
    { sp: 'Mia', text: '对话里的说话人写在这里' }
  ],
  vocab: [ /* 见下 */ ],
  grammar: [ { point, sent, explain, drills: [] } ],
  shadow: ['跟读句1', '跟读句2', '跟读句3'],
  writing: { prompt, hint, mustUse: ['suggest'], model: '范文' }
}
```

词条（`vocab` 里的一项）：

```js
{
  id: 'untouched',                       // 唯一
  word: 'untouched',                     // 卡片上显示的词
  forms: ['untouched'],                  // 正文里所有会出现的形态，正文高亮靠它
  pos: 'adj.', ipa: '/ˌʌnˈtʌtʃt/',
  zh: '未被动过的；保持原样的',
  sense: '这里指书买回来之后一直放在架子上，从来没被翻开过。',
  sent: 'Then it sits there, untouched, for three years.',
  morph: [{ p: 'un-', g: '否定' }, { p: 'touch', g: '碰' }],
  note: 'un- 加过去分词，表示「没有被…过」',
  colloc: [{ en: 'sit untouched', zh: '原封不动地放着' }],
  contrast: { with: 'intact', diff: '两者的区别……' },
  register: '中性，书面口语都常见',
  why: '作者为什么选这个词'
}
```

> `forms` 要写全：正文里出现 `suggests`，`forms` 里就得有 `suggests`，
> 否则那个词不会被标成可点。

## 已知限制

- **不联网、不同步**：数据在 localStorage，换设备、清缓存都会没。做多端同步需要账号系统。
- **朗读用浏览器自带 TTS**：声音取决于系统装的语音包，质量参差。想更好听得接付费 TTS。
- **跟读不评分**：语音识别（Chrome / Edge 有）只给「相似度」参考，不做发音纠正。
- **重新部署后要改缓存版本**：改了 `sw.js` 里的 `CACHE` 名字，否则手机会一直用旧缓存。

## 更新线上版本

改完文件后，把 `index.html` / `assets/` 下改动的文件重新传到
[GitHub 仓库](https://github.com/zhaodafa473-arch/context-english)（网页上可直接拖拽上传，
选「Commit changes」覆盖）。Pages 约 1 分钟后自动重建。

Service Worker 是**网络优先**：联网时会拿最新文件，断网才用缓存，
所以正常情况下手机上刷新一次就生效，不需要清缓存。

如果改了 `sw.js`，记得把里面的 `CACHE` 版本号 +1。

打包用：`python tools/make_zip.py`（生成 `english-app-site.zip`，`index.html` 在 zip 根目录）。
